# Visuels restant à produire

Généré par `node tools/images/generer.js --manquants`. Chaque bloc est un
prompt complet : copiez-le tel quel dans l’outil de génération d’images.
Enregistrez le résultat dans `img/brut/` **sous le nom indiqué**, puis lancez
`node tools/images/optimiser.js` et `node tools/build.js`.
